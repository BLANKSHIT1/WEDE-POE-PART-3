## Website Goals and Objectives
-   to create online presence 
-	Increase awareness of the barber shop and its services.
-	Allow customers to view services and prices 
-	Enable customers to make appointments online.
-	Display previous hairstyles through a gallery.

-	Home page – Introduction, featured services, location map, contact us, Reviews and booking call-to-action.
-	Contact- Contact information, map and contact form.
-	Services & Prices – Haircuts, beard grooming and massage services.
-	Online Booking – Customers can select a service, and date and available time.
-	Gallery – Images showcasing previous hairstyle and available time.
-	About US – Information about the business and barbers.

### Part 1: Initial Setup
- Created the initial website HTML files (Homepage, Appointment, Gallery, Services & Prices, Enquire, Contact).
- Built the main navigation menu to link all pages together.
- Added foundational content, text, and basic image assets.

### Part 2: Feedback Corrections & CSS Styling
- **Part 1 Feedback Corrections:** Fixed missing closing brackets on HTML tags (e.g., the `<link>` tag) and removed misplaced `</body>` tags to ensure clean code structure.
- **External Stylesheet Setup:** Created a central `style.css` file in the CSS_assets folder and properly linked it to the `<head>` of all HTML pages to ensure consistent styling.
- **HTML Restructuring:** Added semantic `<section>` and `<div>` containers with specific class names across all pages to enable advanced CSS layouts.
- **Base Styling & Typography:** Applied the project's dark theme color palette (primary black, dark grey, white text, and purple accents) and set a consistent modern sans-serif typography scale using relative units (rem) across the site.
- **Flexbox Layouts:** Implemented CSS Flexbox to create the responsive top navigation bar, side-by-side split sections (such as the Appointment form and Contact details), and a structured 3-column footer.
- **Grid Layouts:** Utilized CSS Grid to build an aligned 4x2 image layout for the Gallery page and a clean 2-column layout for the Services & Prices page.
- **Form & Interactive Styling:** Styled form inputs, dropdowns, text areas, and radio buttons uniformly across the Appointment, Enquire, and Contact pages. Added visual interactive hover states to the call-to-action buttons.
- **Responsive Design:** Added CSS media queries to establish specific breakpoints for tablet and mobile screens. Programmed flexbox and grid layouts to collapse into single columns on smaller devices to ensure optimal mobile user experience.
  
###Part 3 Enhancement & Feedback Corrections
Fixed (Part 2 Feedback Improvements)
- Responsive Layouts: Added media query breakpoints for tablets (900px) and mobile devices (768px) to resolve off-screen content cut-offs and horizontal scrolling.

- Mobile Navigation: Implemented a mobile hamburger menu drawer to prevent header link overflow on small screens.

- Typography & Styling: Standardized text line-heights, added pseudo-classes (:hover, :focus), and unified dark-theme form control inputs across all pages.

- Gallery Spacing: Converted hardcoded image width styles to a dynamic CSS Grid system to eliminate unnecessary whitespace and fix small image previews.

### Added (Part 3 Functionality & SEO)

- Appointment Form Expansion: Updated Appointment.html to include the full list of studio services organized into <optgroup> categories.
